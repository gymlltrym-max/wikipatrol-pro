# מה התוסף עושה
**עדכון 2.0.0**
1. 👮 מערכת ניטור חכמה: התוסף מזהה את חשבון הויקיפדיה שלכם ואת הרשאות הניטור באופן מאובטח.
2. ❗ סינון "לא בדוקות": למנטרים בלבד – אפשרות להציג בפיד אך ורק עריכות שטרם נבדקו, כדי לחסוך זמן יקר.
3. 🔄 מנוע טעינה משופר: אלגוריתם חדש (Deep Scan) שמבטיח שתמיד תקבלו תוצאות רלוונטיות, גם בסינונים מורכבים.
4. 🔐 אבטחה: עובד על בסיס חיבור הדפדפן הקיים, ללא צורך בהזנת סיסמה.

ויקיפטרול חי פרו מאפשר ניטור עריכות בזמן אמת בוויקיפדיה ישירות מסרגל הצד. כולל זיהוי השחתות חכם (ORES), מצב כהה, סינון אנונימיים ורשימת מעקב אישית. הכלי האולטימטיבי למנטרים שרוצים יעילות מקסימלית ללא צורך ברענון הדף. אפשר לקרוא או לכתוב ערך ויקיפדיה ולהמשיך לנטר. 
תכונות מרכזיות נוספות:
* ⚡ עדכונים חיים: זרם עריכות שמתעדכן אוטומטית (Live Feed).
* 🎯 סינון מתקדם: אפשרות להציג רק אנונימיים, רק את הגרסה האחרונה, או רק עריכות במרחב הערכים (ללא דפי שיחה).
* 🎨 ממשק חכם: צביעת עריכות חשודות באדום (זיהוי השחתה) ועיצוב Dark Mode מודרני.
* 👁️ תצוגה מקדימה: צפייה בהבדלי גרסאות (Diff) בתוך התוסף עצמו.
* 🔔 מעקב אישי: קבלת התראות על משתמשים ספציפיים שבחרתם.
* 🔒 פרטיות: התוסף אינו אוסף מידע אישי ומשמש ככלי עזר לניטור בלבד

## הוראות התקנה ל-Google Chrome (חינמי) גרסה 2.0.0
מכיוון שהתוסף אינו מפורסם בחנות של גוגל (כדי לשמור עליו בחינם), יש להתקין אותו ידנית:

1. לחצו על הכפתור הירוק **Code** למעלה ובחרו ב-**Download ZIP**.
2. חלצו את קובץ ה-ZIP לתיקייה קבועה במחשב שלכם.
3. פתחו את דפדפן כרום והיכנסו לכתובת: `chrome://extensions`.
4. הפעילו את **"מצב מפתח" (Developer mode)** בפינה הימנית/שמאלית העליונה.
5. לחצו על כפתור **"טעינת פריט Unpacked**. 
6. בחרו את התיקייה שבה שמרתם את קבצי התוסף.

# היסטוריה עדכונים
**גרסה 1.0**

התוסף נוצר


**גרסה 1.1.0**
1. ⚡ מהירות שיא: הפיד מתעדכן כעת כל 3 שניות (במקום כל דקה), לניטור בזמן אמת אמיתי.
2. 🔔 התראות קוליות: נוספה אפשרות להשמעת צליל עדין ("דינג") בכל פעם שנכנסת עריכה חדשה לסינון שבחרתם.
3. 🚀 סינון AI מתקדם (ORES): נוסף תפריט סינון חכם המאפשר לכם להתמקד ב"חשד להשחתה" בלבד (🔴) או ב"כוונה טובה" (🟢) בלחיצת כפתור.
4. 🔊 בדיקת מערכת: כפתור חדש לבדיקת תקינות ההתראות והרשאות הדפדפן.
5. תיקוני באגים ושיפורי ביצועים.

**גרסה 1.2.0 + 1.2.1**
1. 🟣 זיהוי מילים חשודות (סגול): הוספנו צבע חדש לרשימה. עריכות המכילות מילים בעייתיות או "סלנג" של משחיתים יסומנו כעת בסגול בולט.
2. 🤖 המערכת הלומדת: התוסף יודע כעת לזהות באופן עצמאי מילים שגורמות לשחזורים חוזרים בוויקיפדיה, ומוסיף אותן אוטומטית לרשימת ההתראות שלך. ככל שתשתמשו בתוסף, הוא יהפוך לחכם יותר.
3. 🛡️ מנגנון בטיחות: הוספנו הגנות מתקדמות כדי להבטיח שמילים לגיטימיות (כמו "תיקון" או "עריכה") לא יסומנו בטעות.
4. תיקוני באגים ושיפורי ביצועים.
5. 🐛 תוקן: רשימת המעקב האישית וההתראות על משתמשים ספציפיים חזרו לפעול בצורה תקינה.
**גרסה 1.3.0**
1. 🚀 סריקה עמוקה (Deep Scan): שיפרנו את מנוע טעינת ההיסטוריה. מעכשיו, כשאתם מפעילים סינון (כמו "אנונימי"), התוסף יסרוק עמוק יותר בהיסטוריית ויקיפדיה כדי למצוא לכם תוצאות רלוונטיות, ולא יחזיר רשימה ריקה.
2. 🕵️ הוספת מילים חשודות חדשות: הוספנו עוד מילים למאגר
